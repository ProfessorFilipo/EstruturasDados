# Revisão — Lista, Pilha e Fila (Bloco 2 da Aula 3)

Cópia dos demos de Lista (Aula 1), Pilha e Fila (Aula 2), reunidos aqui
só por conveniência — para não precisar abrir a pasta de outra aula
durante a apresentação. O código-fonte é idêntico ao das pastas
originais; a referência de implementação continua sendo
`aula01-estruturas-lineares/` e `aula02-pilhas-filas/`.

```bash
make
./contigua
./encadeada
./demo_pilha
./demo_fila
```
